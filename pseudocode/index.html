What is Pseudocode?

Pseudocode is like a recipe for your program written in plain English. Use it to design the logic before writing code.

Think of it this way:

  • Building a house → you need a blueprint first
  • Cooking a meal → you need a recipe first
  • Writing a program → you need pseudocode first

Quick quiz — What is pseudocode?

Quick tip

Write steps in short sentences. Keep keywords like IF, FOR, and INPUT in caps to stand out.

Example: Sum of an array 
FUNCTION SUM_ARRAY(arr)
    SET total = 0
    FOR each item IN arr DO 
        total = total + item
    END FOR
    RETURN total
END FUNCTION
Small examples help bridge idea → code.

Why Use Pseudocode?

  • No confusing syntax — just clear English
  • Catch logic errors early
  • Plan step-by-step solutions
  • Easy to explain to teammates
  • Language-independent

Pro tip

Keep lines short and use indentation to show nested logic — treat pseudocode like readable prose.

Rules for Writing Pseudocode

Write in plain English — keep structure

Short statements, clear verbs, indentation for nesting.

Use CLEAR KEYWORDS

IF, FOR, WHILE, INPUT, PRINT — use CAPS for clarity.

Be specific but not code

Avoid exact syntax — aim for clarity rather than runnable code.
